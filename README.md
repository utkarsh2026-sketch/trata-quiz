# TRATA QUIZ

## Autonomous Disaster Response & Rescue System

TRATA Quiz is an interactive learning and technology platform based around disaster-response technology, robotics, sensors, autonomous systems, science and innovation.

## Features

- Interactive TRATA Quiz
- Randomized questions and answer options
- TRATA Project information
- Swipeable project information cards
- Business Challenge
- Career Explorer
- Career interest graphs
- User quiz history
- Admin analytics dashboard
- Responsive futuristic interface
- English / Hindi interface
- Achievement certificate
- Mobile-friendly design
- Vercel deployment support

## TRATA Project

TRATA explores the use of robotics, autonomous systems, sensors and rescue technology for disaster-response applications.

The project concept includes:

- Rescue rover
- Drone support
- Sensors
- Autonomous navigation
- Disaster-area inspection
- Emergency monitoring
- Technology and innovation

## Quiz

The quiz uses randomized question and answer order.

Correct answers are linked to their option identity rather than assuming that the first option is correct.

## Business Challenge

The Business Challenge presents technology and innovation scenarios involving:

- Problem identification
- Customer needs
- Innovation
- Sustainability
- Resource awareness
- Product planning
- Decision making

## Career Explorer

Career Explorer provides an interest-based exploration profile covering areas such as:

- Robotics
- Software and AI
- Electronics
- Science and research
- Product design
- Entrepreneurship
- Environmental technology
- Disaster technology

The result is an interest exploration tool and is not a psychological assessment or guaranteed career prediction.

## Languages

The application supports:

- English
- Hindi

## Deployment

The project is designed to be deployed using Vercel.

## Important Data Note

The current frontend demonstration stores local activity using browser storage.

For a production multi-user system where an administrator can securely view data from multiple devices, a proper authentication system and cloud database should be connected.
